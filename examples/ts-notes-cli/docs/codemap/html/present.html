      notes-cli를 팀에 소개하기 위한 7장짜리 슬라이드 개요이며, 다섯 개 codemap 문서가 모두 있어 빠진 출처는 없습니다.

      슬라이드 1: 무엇인가

      터미널에서 notes add, notes list로 메모를 다루는 작은 TypeScript 명령줄 도구입니다.

      슬라이드 2: 큰 그림

      사용자 한 명, 프로세스 하나, 메모리 배열 하나로 이루어진 단순한 구조입니다.

      슬라이드 3: 어떻게 구성되어 있나

      CLI, 저장소, 보조, 타입 네 묶음으로 나뉘며 파일은 모두 src/ 아래에 있습니다.

      • notes-cli — 메모를 추가하고 목록으로 보여 주는 작은 명령줄 도구
        • CLI — 명령어를 해석하는 층
          • src/index.ts — add, list 명령 분기와 사용법 출력
        • 저장소 — 메모를 메모리에 보관
          • src/notes-store.ts — 모듈 전역 배열에 메모 보관
        • 보조 — 작성자와 출력 형식
          • src/user-profile.ts — 현재 사용자 이름 제공
          • src/format.ts — 메모 한 줄 문자열 만들기
        • 타입 — 공유 데이터 모양
          • src/types.ts — Note 인터페이스

      슬라이드 4: 어떻게 실행되나

      notes list는 저장소가 각 메모를 포맷터에 넘겨 한 줄씩 만든 뒤 진입 파일이 출력합니다.

      슬라이드 5: 부분들의 의존 관계

      모든 의존이 src/types.ts로 모이고, 순환 의존은 없습니다.

      슬라이드 6: 핵심 설계 선택

      메모는 모듈 전역 배열에만 있어 프로세스가 끝나면 사라지고, 그 이유는 코드에 적혀 있지 않습니다. (추정: 프로토타입이라서)

      또한 출력 형식을 src/format.ts로 분리해 저장 로직과 독립시켰습니다.

      슬라이드 7: 어디부터 읽을까

      README.md, package.json, src/index.ts, src/notes-store.ts 순서로 읽으면 흐름이 잡힙니다.

      다루지 않은 범위

      tsconfig.json과 빌드 산출물 dist/는 읽지 않았고, 소스 5개는 모두 읽었습니다.

      notes-cli는 터미널에서 메모를 추가하고 목록을 보는 작은 TypeScript 명령줄 도구이며, 아래에서 세 단계의 확대 수준으로 구조를 보여 줍니다.

      1단계: 시스템 컨텍스트

  env["환경 변수 USER (process.env)"]:::external
  user -->|"notes add / list"| cli
  cli -->|"결과 / 오류 출력"| user

  classDef external fill:#E3F4F1,stroke:#0E8F83,color:#0B4F49

      사용자가 터미널에서 notes add나 notes list를 실행하고, 도구는 작성자 이름을 얻기 위해 환경 변수 USER를 읽습니다(src/user-profile.ts). 데이터베이스나 네트워크 API 호출은 코드에서 찾지 못했습니다.

      배포 단위는 하나의 CLI 프로세스뿐이며, 메모는 이 프로세스 안의 배열(const notes: Note[] = [])에만 저장되어 프로세스가 끝나면 사라집니다. package.json의 bin은 notes를 빌드 산출물 dist/index.js로 연결하고, npm run build는 tsc를 실행합니다.

      src/index.ts가 명령을 해석해 src/notes-store.ts와 src/user-profile.ts를 호출하고, 저장소는 src/format.ts로 한 줄 문자열을 만들며, 점선은 타입만 가져오는 의존입니다.

      컴포넌트책임
      src/index.tsprocess.argv를 읽어 add / list / 사용법 오류로 분기
      src/notes-store.ts메모리 배열에 메모 추가(addNote), 포맷된 줄 목록 반환(listNotes)
      src/format.ts#id 본문 (작성자) 형식의 문자열 생성(formatNote)
      src/user-profile.tsUSER 환경 변수 또는 "anonymous" 반환(currentUser)
      src/types.tsNote 인터페이스(id, text, author) 정의

      다루지 않은 범위

      소스 파일 5개(src/ 전체)와 README.md, package.json, tsconfig.json을 모두 읽었습니다. 빌드 산출물 dist/와 node_modules/는 저장소에 없어 읽지 않았습니다.

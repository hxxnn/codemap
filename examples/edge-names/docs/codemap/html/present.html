      edge-names 코드베이스를 팀에 소개하기 위한 7장짜리 슬라이드 개요이며, 기존 codemap 문서 5개에서만 내용을 가져왔습니다.

      슬라이드 1: 이게 무엇인가

      고정된 항목 목록을 대문자로 바꿔 출력하는 아주 작은 Node.js 프로그램으로, 파일 이름에 공백과 한글이 들어간 경우를 시험하려는 프로젝트입니다. 외부 패키지는 쓰지 않습니다.

      슬라이드 2: 큰 그림

      프로세스 하나가 사용자의 실행을 받아 결과를 터미널로 내보냅니다. 서버나 데이터베이스는 없습니다.

      flowchart LR
  user["실행하는 사용자"]:::external
  subgraph proc["단일 Node.js 프로세스"]
    cli["CLI 스크립트 (JavaScript, src/)"]
  end
  out["표준 출력 (터미널)"]:::external
  user -->|"실행"| cli
  cli -->|"줄 출력"| out
  classDef external fill:#E3F4F1,stroke:#0E8F83,color:#0B4F49

      슬라이드 3: 어떻게 구성되어 있나

      실행, 데이터, 문자열 변환 세 갈래로 나뉩니다.

      mindmap
  root((edge-names))
    a1["실행"]
      a2["src/main.js: 항목을 불러와 출력"]
    a3["데이터"]
      a4["src/데이터 로더.js: 고정 목록 제공"]
        a5["loadItems()"]
    a6["문자열 변환"]
      a7["src/my utils.js: 대문자 + 느낌표"]
        a8["shout()"]

      슬라이드 4: 어떻게 실행되나

      src/main.js가 항목을 불러온 뒤 하나씩 변환하고 출력합니다.

      sequenceDiagram
  actor U as 사용자
  participant M as src/main.js
  participant L as src/데이터 로더.js
  participant S as src/my utils.js
  participant O as 표준 출력
  U->>M: node 실행
  M->>L: loadItems()
  L-->>M: 배열 복사본 (alpha, beta, gamma)
  loop 항목마다
    M->>S: shout(item)
    S-->>M: 대문자 + 느낌표
    M->>O: console.log(결과)
  end

      슬라이드 5: 파일끼리의 의존 관계

      src/main.js만 다른 두 파일을 가져오며, 순환 의존은 없습니다.

      flowchart LR
  n1["src/main.js"]
  n2["src/my utils.js"]
  n3["src/데이터 로더.js"]
  n1 --> n2
  n1 --> n3

      슬라이드 6: 핵심 설계 선택

      역할별로 파일 하나씩 분리하고, 진입 파일은 조립만 맡습니다. 데이터는 모듈 안의 메모리 배열에 두고 복사본을 돌려줍니다. (추정) 복사본을 돌려주는 이유는 코드에 적혀 있지 않습니다.

      슬라이드 7: 어디서부터 읽을까

      README.md, package.json, src/main.js 순서로 읽고, 그다음 src/데이터 로더.js와 src/my utils.js를 봅니다.

      다루지 않은 범위

      원본 문서들의 범위와 같습니다. 소스 파일 3개와 package.json, README.md를 모두 읽었으며, 읽지 않은 범위는 없습니다.
